# 动画短片《光影之间》

这是一部探索光影与几何视觉边界的 3D 动画短片。

我的创作初衷是打破传统的叙事结构，纯粹依靠视觉张力与动态节奏来讲述故事。在制作过程中，我独立完成了角色建模、材质贴图、骨骼绑定以及最终的动画渲染。

视觉语言直接且充满力量，旨在让每一个镜头在屏幕上都能呈现出电影般的质感。
