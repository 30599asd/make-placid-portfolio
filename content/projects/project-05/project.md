# 商业动画《梦境漫游》

这是一次通过静态与动态影像结合呈现的品牌商业视觉项目。

为了适应不同受众和媒介格式（如社交媒体、线下大屏、品牌官网），我设计了一套极具弹性的视觉结构。在动画表达上，保留了品牌特有的色彩基调，同时通过流畅的转场与动态图形，增强了故事的感染力，让品牌信息在视觉享受中自然传递。
