# 动态交互视觉《界面韵律》

这是一个由精简的、可复用的 UI 组件以及交互原则构建的数字动效系统。

在创作过程中，我关注每一个微交互（Micro-interaction）的物理反馈与时间曲线。从按钮的按压、页面的平滑转场，到复杂信息的视觉层级映射，每一处动态都经过精心设计，旨在为用户带来自然、流畅且充满惊喜的数字体验。
