# 沉浸式空间动画《城市幻境》

这是一个将物理空间与数字影像相连接的环境图形项目，通过动态视觉重新定义了空间的引导、信息传递与整体氛围。

在项目中，我利用投影映射（Projection Mapping）技术，将二维的动态图形与三维的建筑结构精准贴合。光影的流动与观众的互动交相辉映，让原本静止的物理空间拥有了呼吸感和生命力，为体验者营造出一场如梦似幻的沉浸式旅程。
