# 系列动画企划《星尘物语》

这是一个旨在支撑广泛传播的动画 IP 视觉平台，在保持独特艺术视角的同时，实现跨媒介的品牌与视觉延展。

在项目中，我不仅完成了核心角色与场景的视觉开发，还建立了一套具有极高包容性的视觉语言系统。这套系统能够适配从短片预告、社交媒体图文到线下实体周边的各种应用场景，确保每一次露出都能强化观众对 IP 的认知与共鸣。
