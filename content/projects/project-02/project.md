# 动态图形包装《城市脉搏》

这是一个围绕清晰的视觉层级、精准的动态节奏，以及克制而富有张力的图文关系所构建的动态图形项目。

在创作中，我尝试让文字与影像在空间中产生共鸣。通过不同比例的画幅切换、时间节奏的把控以及视觉元素的编排，让作品在保持高度秩序感的同时，展现出现代都市的呼吸与律动。
